# **App Name**: GarmentFlow

## Core Features:

- Worker Management: Add/Edit worker info: ID, Name, Designation, Department, Join Date, Basic Salary, Contact, Photo. QR Code generation for each worker
- Attendance System: Mark daily attendance (manual or QR scan). Track present, absent, late entry. Monthly attendance report
- Overtime & Production Entry: Add daily overtime hours. Piece count input per worker. Auto overtime calculation
- Salary Management: Salary formula: (Basic Salary + Overtime + Bonus + Production Pay) - (Advance / Absence Deduction). Auto salary slip generation (PDF & Excel export). Monthly summary & search filter
- Advance & Bonus System: Record advance payment. Deduct from next month salary. Festival / performance bonus options
- Dashboard & Reporting: Graphs: total workers, monthly salary cost, attendance rate. Downloadable report: PDF, Excel. Expense summary
- Notification System: Reminder for salary day. SMS / WhatsApp / App notification
- Security & Backup: Role-based login. Activity log. Auto cloud backup (Google Drive option)

## Style Guidelines:

- Primary: #10B981 (Emerald Green)
- Secondary: #065F46 (Deep Green)
- Background: #F9FAFB (Off White)
- Accent: #A7F3D0 (Soft Green tone)
- Text: #0F172A
- Buttons: Solid Green + White text
- Font: 'Inter' sans-serif for a modern, machined, objective, neutral look. It will be used for both headlines and body text.
- Lucide React icons will be used throughout the application for a consistent and modern look.
- Modern enterprise dashboard layout with rounded cards (radius: 2xl) and minimal shadows.
- Smooth transitions using Framer Motion to enhance user experience.
